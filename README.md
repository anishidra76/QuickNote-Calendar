# Quick Note  -  Personal Notes

    Video link (YouTube) : https://youtu.be/s4pdj-0nr8g



# Description:

    =>  Quick Note is a simple and user-friendly web application for managing personal notes. It was developed as my CS50x Final Project using Python and Django for the backend, SQLite for data storage, and HTML, CSS, and JavaScript for the frontend.

    =>  The application allows users to create, organize, edit, and delete personal notes, as well as assign specific dates to them and view scheduled notes through an integrated calendar.

    =>  Quick Note includes user registration, secure login and logout, personal note management, date-based scheduling, and a clean, responsive interface. Each user's notes are associated with their account, ensuring that users can only access their own personal data.

    =>  Through this project, I applied concepts learned throughout CS50x, including Python programming, Django web development, CRUD operations, database management, authentication, forms, template rendering, and frontend-backend integration.

    =>  I also learned how to structure a web application, connect Django with a database, manage user-specific data, and build a practical application focused on productivity and everyday use.
